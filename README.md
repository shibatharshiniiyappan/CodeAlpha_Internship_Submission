## 🛍️ Task 1 — LUMEN Studio: Simple E-Commerce Store

### Overview

LUMEN Studio is a modern e-commerce application designed to provide a convenient online shopping experience. Users can explore products, view product details, manage their shopping cart, and interact with order-related features.

### Key Features

- Product catalog with product details
- Product search and sorting
- Shopping cart functionality
- User registration and login implementation
- Order processing and order history
- Responsive and modern user interface

### Technology Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication:** bcryptjs and JSON Web Tokens (JWT)

### Project Links

- **Live Demo:** [LUMEN Studio](https://codealpha-simpleecommercestore-bgzd.onrender.com/)
- **Source Code:** [CodeAlpha_SimpleEcommerceStore](https://github.com/shibatharshiniiyappan/CodeAlpha_SimpleEcommerceStore)

## 🎥 Task 2 — NEXMEET: Real-Time Communication Platform

### Overview

NEXMEET is a web-based communication platform designed to support online meetings and collaborative activities. It provides interactive features intended to make remote communication and teamwork more convenient.

### Key Features

- Real-time video meetings
- Screen sharing
- File sharing
- Collaborative whiteboard
- Meeting rooms and host controls
- Real-time communication and signaling

### Technology Stack

- **Frontend:** React and TypeScript
- **Backend:** Node.js and Express.js
- **Real-Time Communication:** WebRTC and Socket.IO
- **Styling:** CSS

### Project Links

- **Live Demo:** [NEXMEET](https://codealpha-nexmeet.onrender.com/)
- **Source Code:** [CodeAlpha_NEXMEET](https://github.com/shibatharshiniiyappan/CodeAlpha_NEXMEET)

## 🎓 Task 3 — SmartLearn: Smart Learning Management System

### Overview

SmartLearn is a web-based learning management platform featuring a modern dashboard and dedicated sections for courses, examinations, and learning analytics. It aims to provide learners with a centralized and user-friendly learning interface.

### Key Features

- Learning dashboard
- Course browsing interface
- Examination and assessment section
- Learning analytics dashboard
- Modern purple-themed user interface
- Organized navigation between learning sections

### Technology Stack

- **Frontend:** React 19 and Vite
- **Backend:** Node.js and Express.js
- **Styling:** CSS
- **Icons:** Lucide React

### Project Links

- **Live Demo:** [SmartLearn](https://codealpha-smartlearn.onrender.com/)
- **Source Code:** [CodeAlpha_SmartLearn](https://github.com/shibatharshiniiyappan/CodeAlpha_SmartLearn)
